# Northlight shed uprights

Complete 32-shed Becher overlay, retaining the previous roof ridge fix.

All six northlight variants now have solid 1-pixel-scale wall-material uprights at both ends of each glazing run. Medium lengths have one intermediate upright; longer runs have two. Compact variants retain only the two end uprights. All uprights use existing rings geometry.

No shaders, renderers, compositor, or geometry methods changed.

Install from Becher root: `unzip -o shed_wide_range_northlight_uprights.zip`
