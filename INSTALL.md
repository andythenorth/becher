# Mining and quarry — curated geometry patch

Install from the Becher project root:

```bash
unzip -o becher-mining-quarry-final.zip
```

The ZIP replaces only `data/assemblies/vocabularies.json` and adds eight assembly JSONs.
The `Mining and aggregates` vocabulary remains one vocabulary. The old `mining_graph_*` files may remain on disk but are no longer selected. Other vocabulary memberships are unchanged.

Approved quarry sources: quarry_mass_02, quarry_mass_11, additional quarry variants 05, 06, 10.
Other mining components: mining_graph_56 and 57 enlarged to address earlier small scale, plus balanced headframe D from the earlier approved direction.

This is a deliberately conservative curation rather than restoring the rejected 55-component selection.

Validation: all eight compile, all four placements fit, all 32 native renders produced through render-component. Visual selection remains subjective; the three non-quarry additions have not received final user approval.
